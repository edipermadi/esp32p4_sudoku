Sudoku web flasher

Installs the Sudoku firmware on a Waveshare ESP32-P4-WIFI6-Touch-LCD-4B straight from the browser: no Arduino IDE, no esptool.

This browser can't flash a board. Use Chrome or Edge on a desktop computer (Web Serial isn't in Firefox, Safari or mobile browsers). The page needs HTTPS. Open it from its GitHub Pages address, or from http://localhost.

How to install

  1. Plug the board's UART USB-C port into the computer (not the USB OTG port).
  2. Click Connect and install and pick the port: USB Single Serial (the CH343 chip). On Windows, if nothing shows up, install the CH343 driver from WCH first.
  3. Choose Install. Leave Erase device unticked to keep the board's Wi-Fi setting. Tick it only for a fresh start.
  4. Wait for the flash (about a minute). The board restarts into Sudoku by itself.

What's kept

  • Games, statistics, players and settings are on the microSD card (sudoku.db). Flashing never touches the card.
  • The Wi-Fi network is kept in the board's flash, unless Erase device is ticked.
  • A board that already runs Sudoku can also update itself without a computer link: put the release's update.bin on the card and use Settings → Data → Firmware update.

After installing

The documentation covers how to play, every feature, and where your games and statistics are kept.

Which boards

These builds are for pre-v3.00 ESP32-P4 chips, which most 4B boards have, with 32 MB flash and PSRAM. If the board doesn't start after flashing, its chip may be v3 or newer: build from source with the matching Chip Variant instead.
