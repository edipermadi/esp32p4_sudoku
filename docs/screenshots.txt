# Screenshots for the docs: python3 tools/devctl.py --port /dev/ttyACM0 --script docs/screenshots.txt
# Opening the port restarts the board, so this starts on a fresh Home screen.
# Coordinates are screen pixels (720 x 720). Each "expect" checks where the board is
# (devctl "screen") and stops the run if a tap or swipe didn't land: the taps after
# it would otherwise hit another screen (a game, once). Nothing here changes the game data
# (no puzzle is played or made, no setting is changed). The game screen tour must
# have been seen (tour.png is taken by hand). It expects one recorded
# solve (for Gameplays and the replay) and a puzzle file (.sdx, .sdm or .opensudoku)
# first in puzzles/ (for the preview); the Home menu always has its two pages.
